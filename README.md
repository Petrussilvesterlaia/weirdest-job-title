A Python program that writes one job title — "Professional Goose Apologizer" — to `/output/entry.txt` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. The title is validated (1–60 characters, a single line, not blank), written exactly, then read back and verified. Running it twice produces byte-identical output.

## Run it

```sh
python3 main.py
```
